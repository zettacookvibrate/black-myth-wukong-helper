## 🧩 About

**Black Myth Wukong Helper** is a comprehensive overlay utility for Black Myth Wukong featuring a game overlay menu, stat viewer, loot radar, map tracker, and config presets.

Based on popular tools like **Wukong Overlay**, **BWM Helper**, and **Monkey Menu**.

---

## ✨ Features

### 🎮 Core Overlay
- In-game overlay menu — toggle with a hotkey
- Stat viewer — check health, stamina, mana, and stats live
- Loot radar — highlight nearby items and chests
- Map tracker — show player position and points of interest

### 🎨 Interface & Quality of Life
- Custom HUD — reposition and resize overlay widgets
- Config presets — save and load overlay layouts
- FPS counter — monitor performance in real time
- Hotkey rebinding — change every menu key

### 🏋️ Training & Utility
- Boss practice tracker — record attempts and timings
- Route planner — mark farming routes on the map
- Damage log — view recent hits and sources
- Save backup — export and restore config profiles
